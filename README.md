# Lógica de Programação

Repositório de exercícios e exemplos práticos para aprender lógica de programação em Python e C. O foco está em conceitos fundamentais como estruturas de decisão, repetição, funções, listas e manipulação de dados.

## Estrutura do projeto

- `Exercícios_em_C/`
  - Exercícios em linguagem C com algoritmos básicos e estruturas clássicas.
- `Exercícios_em_Python/`
  - Exercícios em Python voltados a cálculos, manipulação de dados, estruturas de dados e pequenos projetos.

## Conteúdo abordado

- Controle de fluxo: `if`, `else`, `switch`
- Repetição: `for`, `while`
- Funções e modularização
- Estruturas de dados simples: listas, pilhas e filas
- Operações matemáticas e lógicas
- Entrada e saída de dados
- Resolução de problemas passo a passo

## Como usar

1. Abra o repositório no seu editor ou IDE preferido.
2. Navegue até a pasta `Exercícios_em_C` ou `Exercícios_em_Python`.
3. Abra o arquivo do exercício desejado.
4. Execute ou compile conforme a linguagem:
   - Python: `python nome_do_arquivo.py`
   - C: compile com `gcc` ou use seu ambiente de desenvolvimento.

## Exemplos de exercícios

- C:
  - `bubble_sort.cpp`
  - `calculadora_de_IMC.cpp`
  - `fatorial.cpp`
  - `fibonacci.cpp`
- Python:
  - `calcular_media_notas.py`
  - `resolver_equacao_segundo_grau.py`
  - `estrutura_fila_fifo.py`
  - `lista_encadeada_tarefas.py`

## Boas práticas

- Use nomes de variáveis claros e significativos.
- Comente trechos importantes do código.
- Teste com diferentes entradas.
- Refatore etapas repetidas em funções.

## Objetivo

Este repositório é um guia prático para quem está começando a programar e deseja consolidar os conceitos de lógica usando exemplos reais em Python e C.
