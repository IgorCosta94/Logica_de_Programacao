# Exercícios em C

Esta pasta contém exercícios em C desenvolvidos durante meus estudos com o livro **C: Como Programar** (Deitel & Deitel).

## Arquivos Incluídos

- `calculadora_de_imc.cpp` — Cálculo de IMC com validação básica.
- `bubble_sort.cpp` — Implementação do algoritmo Bubble Sort para arrays.
- `fibonacci.cpp` — Cálculo iterativo da série de Fibonacci.
- `fatorial.cpp` — Cálculo do fatorial com verificação de entrada.
- `descubra_o_numero.cpp` — Jogo de adivinhação com validação de entrada.
- `comparacao_de_partes_de_strings.cpp` — Demonstra o uso de `strncmp` e `memcmp`.
- `conversao_de_temperaturas.cpp` — Conversão de Fahrenheit para Celsius.
- `media_soma_produto_maior_menor.cpp` — Operações básicas (soma, média, produto, maior e menor).
